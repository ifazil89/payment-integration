Add these helpers to the key-helpers section:

java
    /** The external folder, checked at startup; null when not configured (then only full locations work). */
    private static Path certificateDir(String dir) {
        if (dir == null || dir.isBlank()) {
            return null;
        }
        Path path = Path.of(dir).toAbsolutePath().normalize();
        if (!Files.isDirectory(path)) {
            throw new IllegalStateException("wallet.apple-pay.certificate-dir (APPLE_PAY_CERT_DIR) is not a folder: "
                    + path);
        }
        if (!Files.isReadable(path)) {
            throw new IllegalStateException("wallet.apple-pay.certificate-dir is not readable by the application user: "
                    + path);
        }
        log.info("Apple Pay certificate folder: {}", path);
        return path;
    }

    /**
     * Where a file is:
     *   "classpath:apple/x.cer", "file:/etc/x.p12"  -> as written
     *   "/opt/certs/x.p12" (absolute path)          -> that file
     *   "apple-pay.p12" (plain name)                -> certificate-dir/apple-pay.p12
     */
    private static Resource resource(String location, Path certificateDir, ResourceLoader resourceLoader) {
        if (location == null || location.isBlank()) {
            throw new IllegalStateException("Apple Pay file location is empty (keystore / root-ca-certificate)");
        }
        if (location.startsWith("classpath:") || location.startsWith("file:")) {
            return resourceLoader.getResource(location);
        }
        Path path = Path.of(location);
        if (!path.isAbsolute()) {
            if (certificateDir == null) {
                throw new IllegalStateException("'" + location + "' is a plain file name but "
                        + "wallet.apple-pay.certificate-dir (APPLE_PAY_CERT_DIR) is not set");
            }
            path = certificateDir.resolve(location).normalize();
        }
        return new FileSystemResource(path);
    }

    private static String describe(Resource resource) {
        try {
            return resource.getFile().getAbsolutePath();
        } catch (IOException ex) {
            return resource.getDescription();   // classpath resource inside the jar
        }
    }

3. application.yml: the apple-pay block

yaml
  apple-pay:
    enabled: ${APPLE_PAY_ENABLED:true}
    merchant-identifier: ${APPLE_PAY_MERCHANT_ID:}       # e.g. merchant.com.company.shop
    # Folder on the server with the Apple Pay files. Plain file names below are looked up here.
    certificate-dir: ${APPLE_PAY_CERT_DIR:/opt/checkout/certs/apple-pay}
    root-ca-certificate: ${APPLE_PAY_ROOT_CA:AppleRootCA-G3.cer}
    max-token-age: 5m
    keys:
      - keystore: ${APPLE_PAY_KEYSTORE:apple-pay.p12}
        keystore-password: ${APPLE_PAY_KEYSTORE_PASSWORD:}
        alias: ${APPLE_PAY_KEYSTORE_ALIAS:}

4. application-local.yml: use a folder on your machine:

yaml
wallet:
  apple-pay:
    certificate-dir: ${APPLE_PAY_CERT_DIR:${user.home}/checkout-certs/apple-pay}

Folder on QA and production:

/opt/checkout/certs/apple-pay/
├── apple-pay.p12          chmod 400, owned by the app user
└── AppleRootCA-G3.cer
Docker or Kubernetes: mount a volume or a Secret at that path, for example -v /secure/apple-pay:/opt/checkout/certs/apple-pay:ro.
Password: pass APPLE_PAY_KEYSTORE_PASSWORD as an environment variable or secret, never in the yml or the folder.
Rotating certificates: put the new .p12 in the same folder and add a second keys entry. Both work until the old one is removed. Restart the app to pick up the new file.

Startup: if the folder or a file is missing or can’t be read, or a plain file name is given with no folder set, the app stops at startup and the message names the full path. When it works, the log shows Apple Pay certificate folder: /opt/... and the line for each loaded key.
